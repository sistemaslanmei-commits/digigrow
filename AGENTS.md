# DigiGrow: instrucciones permanentes

## Proyecto

- Proyecto local: `/home/lanmei/projects/digigrow`.
- Objetivo: publicar una Fase 1 funcional el sábado 31 de octubre de 2026.
- Tecnologías previstas: Laravel Sail, Docker Desktop, Ubuntu WSL2, MySQL y Redis.

## Orden obligatorio de desarrollo

Seguir este orden: **Entorno → Laravel → Filament → Base de datos → Catálogo → Web → WhatsApp → Diseño → Seguridad → VPS → Lanzamiento**. Consultar `PLAN_DESARROLLO.md` para el cronograma y `ESTADO_PROYECTO.md` para el avance comprobado y el siguiente entregable.

## Forma de trabajo

- Antes de trabajar, confirmar que el directorio de trabajo sea la raíz del proyecto indicada arriba y leer estas instrucciones.
- Mantener las fechas y tareas aprobadas en `PLAN_DESARROLLO.md`; cualquier replanificación requiere autorización del usuario.
- Marcar tareas como completadas solo con evidencia verificable. Distinguir claramente los reportes del usuario de las verificaciones realizadas en el entorno.
- No instalar paquetes, ejecutar migraciones, ni modificar código, dependencias o datos salvo que el usuario lo autorice expresamente.
- Para tareas de documentación, limitar los cambios a los documentos solicitados.
- Al finalizar el trabajo solicitado, resumir los cambios y esperar autorización antes de iniciar la siguiente fase de implementación.
